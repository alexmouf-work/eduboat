# CLAUDE.md

**Read [AGENTS.md](AGENTS.md).** It is the entry point for every contributor to this
repository, agent or human: the charter's Tier 0 core verbatim, where work happens, house
style, and pointers to everything else.

**Writing anything the site teaches?** Read
[docs/charter/teaching-copy-style.md](docs/charter/teaching-copy-style.md) first — the house
voice for every word the learner reads. The charter's §6.5 governs what you write back to the
principal; that document governs everything the site says to the learner.

**About to commit?** Commits here are authored by the principal, the human answerable for the
change, never by the agent that wrote it. Set `user.name` and `user.email` accordingly, and add no
`Co-Authored-By` trailer. Charter §6.5.

This file deliberately holds no rules of its own. Two documents stating the same rule drift,
and the copy that drifts is the one people read.
